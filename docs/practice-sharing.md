# 완료 화면과 공유 보너스

로그인한 사용자가 오늘의 기본 연습을 마치면 알파카, 칭찬, 연속 연습 일수와 공유 버튼 하나를 표시한다. 공유 후 보너스 질문 한 개를 열고, 별도의 녹음을 저장할 수 있다. 다음 질문이 열리는 한국 시간 자정도 작게 표시한다.

## 로그인 전의 기록 표시

로그인 전에는 계정의 누적 기록을 알 수 없으므로 스트릭과 계정 체험 횟수를 표시하지 않는다. 임시 연습 완료 화면도 오늘 완료 여부만 표시한다. 언어 선택 화면, 질문 화면 상단과 설정에서 녹음 없이 로그인할 수 있다. 이미 계정에 연결한 방문 정보가 남아 있는 기기는 세션 만료 시 기존 로그인 화면으로 이동한다. 로그인 시 저장된 연습 기록을 그대로 읽고, 오늘 완료했다면 재녹음을 요구하지 않는다.

## 번역 후 녹음

오늘의 기본 연습과 공유 보너스 모두 답변을 영어로 번역한 뒤 녹음할 수 있다. 번역 전에는 마이크 대신 선택한 모국어로 먼저 번역하라는 안내를 표시한다. 질문의 모국어 번역이나 예시만 받은 상태, 번역 실패, 전날 번역으로는 녹음 업로드를 허용하지 않는다. 화면뿐 아니라 서버에서도 해당 사용자의 당일 답변 번역을 확인한다.

완료 시 서버의 기존 번역 결과 중 영어 문장을 `english_sentence`에 녹음과 함께 저장한다. 클라이언트가 보낸 문장 값은 사용하지 않는다. 음성 인식 API는 호출하지 않으며 이 문장은 음성 전사문이 아니다. 로그인으로 임시 녹음을 계정에 연결하거나 AI 임시 응답을 정리해도 저장된 문장은 유지된다. 완료 화면과 공유 카드에 기본·보너스 문장을 표시한다. 과거 녹음에 문장 텍스트가 없으면 추정하지 않고 생략한다.

## 공유 카드

완료 화면의 공유 버튼은 카드 미리보기를 연다. 여기서 카드 공유를 누르면 미리 본 것과 동일한 1080×1350 PNG를 운영체제 공유창에 전달한다. 설치된 이미지 공유 지원 앱을 선택할 수 있다. 한국어는 ‘오공완!’, 일본어·스페인어·중국어 간체·번체는 자연스러운 현지 표현을 사용한다.

카드에는 `Say One Thing`, 알파카, 완료 문구, 실제 연속 연습 일수와 App Store·Google Play 배지, 그 아래 앱 이름 검색 안내를 넣는다. 검색어 `Say One Thing`은 그대로 두고 안내 문구를 각 언어로 표시한다. 반복 문구와 주간 달력, 날짜, URL은 이미지에서 생략한다. 스토어 배지도 각 언어의 공식 아트워크를 사용하며 출처는 `docs/design/store-badges.sources.txt`에 기록한다. 이메일과 음성 파일은 포함하지 않는다. 녹음에 사용한 영어 번역 문장은 카드에도 표시하며, 아주 긴 문장은 카드에서만 말줄임하고 완료 화면에서는 전체를 표시한다. 현재 화면의 언어와 서버가 계산한 기록을 사용하며, Canvas로 기기에서 생성하므로 Gemini 호출이나 API 비용이 추가되지 않는다.

카드는 공유창을 열기 전에 생성해 두며, 두 번째 탭에서 OS 공유 API를 바로 호출한다. 공유창을 열기 위한 사용자 동작이 비동기 이미지 생성 중 소실되지 않게 한다.

## 보상 규칙

- 기본 연습 한 건당 `BonusPractice` 한 건만 생성한다. DB 고유 인덱스와 트랜잭션 잠금으로 중복 지급과 중복 Gemini 생성을 막는다.
- 로그인 상태, 기본 연습 소유자, 한국 시간 기준 오늘인지, 서명 토큰을 서버에서 검증한다. 완료 화면에서 만든 공유 토큰은 자정에 만료된다.
- 보너스는 당일에만 사용할 수 있다. 녹음 재전송은 기존 파일을 교체하거나 보상을 추가하지 않는다.
- 기본 연습 기록이 스트릭과 무료 훈련 사용일을 계산한다. 보너스는 별도로 저장하므로 무료 체험은 여전히 서로 다른 3일이다.
- 보너스 질문은 날짜별로 공유하며 기존 질문과 중복되지 않게 한다. 보너스 표현 도움말은 별도의 하루 1회 한도를 쓰고 응답을 재사용한다.
- 관리자 화면에서 기본 녹음과 보너스 녹음을 모두 들을 수 있다. 계정 삭제 시 보너스 녹음도 삭제한다.

## 공유 완료의 의미

공유하는 내용은 PNG 카드, 연속 연습 일수와 앱 링크다. 미리보기나 이미지 다운로드만으로는 보상을 지급하지 않는다. 공유창 취소는 보상을 지급하지 않는다. iOS는 `UIActivityViewController` 완료 콜백, Android는 공유 대상 선택 콜백, 브라우저는 Web Share API의 성공 반환을 사용한다. 이 콜백은 다른 앱으로의 전달을 뜻하며 친구의 실제 수신이나 메시지 전송까지 증명하지 않는다. 서버는 공유 사실을 독립적으로 검증하는 영수증을 받지 않으므로, 보상은 소유자별 당일 한 건으로 제한한다.

근거: [W3C Web Share API](https://www.w3.org/TR/web-share/), [Apple 완료 콜백](https://developer.apple.com/documentation/uikit/uiactivityviewcontroller/completionwithitemshandler-swift.property), [Android 공유 대상 선택](https://developer.android.com/training/sharing/send).

이미지 파일 공유를 지원하지 않는 브라우저에서는 카드 다운로드를 제공한다. iOS는 검증한 PNG를 `UIImage`로 공유하며, Android는 전용 캐시 폴더에 PNG를 쓰고 읽기 권한을 한정한 `FileProvider` URI로 공유한다. 두 앱 모두 허용된 서버의 메인 프레임 요청, 이미지 크기와 용량을 확인한다. Android 공유 파일은 다른 앱이 읽을 수 있도록 유지하고 다음 내보내기 때 24시간 지난 파일을 정리한다.

네이티브 이미지 공유 브리지는 업데이트한 iOS·Android 바이너리에 포함된다. 기존 설치본에 이 기능을 제공하려면 각 앱도 업데이트해야 한다. [Android 파일 공유 문서](https://developer.android.com/training/secure-file-sharing/share-file).

## 배포

사용자 요청으로 `english_sentence`를 `CreateDailyPractices`와 `CreateBonusPractices`에 각각 통합했다. 별도의 컬럼 추가 마이그레이션은 삭제했다. 새 DB에서는 테이블 생성 시 문장 컬럼도 함께 생성된다. 문장 컬럼은 기존 기록을 보존하도록 NULL을 허용한다.

기존 DB에서는 이미 적용한 생성 마이그레이션이 다시 실행되지 않는다. 따라서 문장 컬럼이 없는 운영 DB는 배포 전에 해당 컬럼을 별도로 추가해야 한다. 컬럼과 데이터가 이미 있는 로컬 DB는 그대로 유지하고, 삭제한 마이그레이션 버전의 적용 기록만 정리했다. 서버와 네이티브 앱 업데이트는 별도로 배포한다.

캐릭터는 내장 image_gen 도구로 생성한 새 이미지다. [프롬프트](design/alpaca-celebrate.prompt.txt), [프로젝트 이미지](../app/assets/images/alpaca-celebrate.png).
